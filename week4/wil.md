# 확률 예측 문제
어떠한 데이터의 input을 보고 어떤 확률로 무슨 target에 속할지 맞추는 문제를 풀 때, KNN 알고리즘을 이용할 확률이 n/(살펴보는 이웃의 개수)로 제한되어서 특정 값의 배수로만 확률이 나타내어진다는 한계가 있다.

# 로지스틱 회귀
이름은 회귀지만 실제로는 분류 모델로, 각 특성을 이용한 선형방정식으로 나타내어진다.   
z = ax1 + bx2 + ... + f(z는 0과 1 사이의 확률값)   
시그모이드 함수: 음의 무한대로 가면 0, 양의 무한대로 가면 1에 가까워지는 함수

# 점진적 학습
기존에 이미 학습을 시킨 모델에 추가로 데이터를 넣어서 훈련을 시키는 방법

# 손실함수와 경사하강법
* 손실함수: 오차의 크기를 나타낸 함수, 작을수록 오차 작음
* 경사하강법: 그래스의 경사를 따라 내려가서 경사가 없는 최저점을 찾아 이동하는 기법
* 에포크: 전체 데이터셋으로 경사하강법을 한 번 쓰는 과정을 나타낸 단위
과적합이 나타나지 않는 적절한 에포크 값 찾는 것이 중요함.

# 배운 점
지금까지는 데이터를 한번에 모두 학습하고 추가적인 데이터 학습 없이 모델을 만들었으나, 오늘 처음으로 새로운 데이터를 기존 모델에 추가하는 SGD(확률적 경사 하강법)를 배웠다. 다만 이 방식을 이용했을 때 기존 데이터가 버려지지 않고 새로운 데이터를 계속 받을 수 있다는 방식이 이해하기 어려웠어서 추가적으로 조사해본 결과, 기존 데이터들을 계속 소장하는 방식이 아니라 학습에 이용한 후 버리는 식으로 저장공간 낭비 없이 많은 양의 데이터를 처리할 수 있었다는 것이 놀라웠다.
